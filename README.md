# Lexi — Learn English

A polished, responsive English-learning app with daily lessons, topic cards, weekly goals, quick quizzes, and progress tracking.

## Run locally

Open `index.html` directly in a browser, or serve the folder with:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Features

- Learn, practice, and progress views
- Three-question interactive quiz
- XP and lesson progress saved in browser local storage
- Responsive desktop and mobile layouts
- No build step or dependencies
